# 从注意力到两层 Transformer

给定 `[10, 20, 30]`，一个语言模型怎样选出下一个 token？这里沿着一次前向计算，把词嵌入、因果自注意力、门控前馈层和词表投影接成一个可训练的 PyTorch 模型。两条合成序列就足够观察预测分数、参数更新和逐个生成 ID 的全过程。

[打开六个张量实验](walkthrough.ipynb) · [读完整模型](model.py#L60) · [看一次训练与生成](demo.py)

| 在哪一步观察 | 可以看见什么 |
| --- | --- |
| [单头](attention.py#L6)与[多头因果注意力](attention.py#L59) | 权重表的每一行和为 1，未来位置的权重为 0。修改序列末尾的输入，前面位置的输出保持一致。 |
| [RoPE](attention.py#L138) | 将 Q、K 的相邻特征配对旋转。同一向量在不同位置得到不同方向，每对特征的长度保持不变。 |
| [RMSNorm](layers.py#L9)、[SwiGLU](layers.py#L39) 与[残差块](layers.py#L70) | 注意力分支可以读取之前的位置，前馈分支在每个位置独立计算。两个分支的输出依次加回原来的表示。 |
| [两层语言模型](model.py#L60)与[贪心生成](model.py#L115) | 每个位置得到一组词表分数。生成时取最后一个位置分数最高的 ID，追加到输入后再做下一次预测。 |
| [开销估算](architecture.py) | 用模型宽度、层数和词表大小手算参数量，再与 PyTorch 注册的参数逐个相加核对。 |

## 运行原例

在仓库根目录执行以下命令。模型使用 CPU 和两条合成序列，训练目标是每个位置的下一个 ID。

```sh
python -m pip install torch
python cs336-transformer/demo.py
```

| 这次实验 | CPU 复跑结果 |
| --- | --- |
| 输入和输出 | 两条四个位置的输入，每个位置预测 260 个候选 ID，输出形状为 `[2, 4, 260]` |
| 模型 | 2 层、2 个注意力头、隐藏宽度 8、前馈宽度 16，共 5,480 个可训练参数 |
| 一次更新 | 学习率 0.1 的 SGD 让同一批输入的交叉熵从 5.5791 变为 5.4766 |
| 贪心生成 | 原例以 `[10, 20, 30]` 开始，在这次运行中依次追加 `[185, 222, 186, 97, 240]` |
| 前向计算 | 在本例尺寸下，主要矩阵乘法约 55,808 FLOPs，每层注意力权重共有 64 个元素 |

原例固定了随机种子，显示的 ID 用来核对生成流程。开销估算对一次乘加计两次浮点运算，统计注意力投影、注意力混合、前馈层和输出投影的矩阵乘法。
