# 模拟电商订单分析

用 pandas 清洗订单编号、渠道与日期字段，按月汇总实付金额，再比较商品与渠道的变化。Notebook 内含全部模拟数据，覆盖 18 笔不同订单，两个字段按练习给定的信息补齐。

六月和七月的销售额分别为 2600 元和 1600 元。平台渠道均为 950 元，官网咖啡壶的销售额减少了 900 元。可以据此缩小排查范围；仅凭订单无法判断缺货、下架或流量变化的影响。

在此目录执行 `python -m pip install -r requirements.txt`，然后运行 `jupyter lab sales_analysis.ipynb` 并从头执行全部单元。若图表中文字未显示，请选择已安装的中文字体。
